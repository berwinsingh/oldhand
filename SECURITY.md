# Security Policy

## Supported versions

Security fixes apply to the latest release and `main`.

## Report a vulnerability

Use GitHub's [private vulnerability reporting form](https://github.com/berwinsingh/oldhand/security/advisories/new). Do not open a public issue or discussion.

Include:

- the affected version and platform;
- the smallest safe reproduction;
- the impact and affected users;
- any suggested mitigation; and
- only logs or screenshots that contain no secrets or private project data.

The maintainer will confirm the report, investigate it privately, and coordinate disclosure after a fix is available. Please do not publish the vulnerability before that coordination is complete.
